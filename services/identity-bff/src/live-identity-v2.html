O que esta página pode provar

Login via Authorization Code + PKCE e ID token validado pelo BFF; token de acesso ativo e scopes lidos do WSO2; decisão real da API protegida com ciam:profile:read.

Escopos OAuth não representam automaticamente funções de negócio ou papéis. Dados de perfil somente são apresentados se estiverem em claims do ID token assinado e validado.

Capacidades não habilitadas

Consentimento, assurance por atributo, MFA/step-up, identidade de agentes, hierarquia B2B, histórico de compras e encerramento de SSO no WSO2 não são simulados por este portal. Sua demonstração depende de implementação e teste próprios.

Em modo live, nenhum clique seleciona ou troca artificialmente um usuário. Para trocar de conta, autentique-se novamente no WSO2; encerrar a sessão local não encerra necessariamente a sessão SSO do IdP.
